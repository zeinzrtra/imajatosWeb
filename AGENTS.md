# UI/UX working instructions

Before making or reviewing UI, UX, visual design, content-design, accessibility, or frontend-presentation changes:

1. Read the private knowledge base at `https://github.com/RAFeps/codex-uiux-knowledge`.
2. When both repositories are cloned as siblings, start with:
   - `../codex-uiux-knowledge/START-HERE.md`
   - `../codex-uiux-knowledge/projects/imajatos.md`
   - `../codex-uiux-knowledge/checklists/design-review.md`
3. Use verified IMAJATOS information over placeholders.
4. Never invent impact numbers, people, partners, testimonials, programs, or organization history.
5. Keep sponsorship, partnership, contact, privacy, and complaint language clear and professional.
6. Run the knowledge-base design review checklist before presenting or shipping frontend changes.
